# Motjo — Pages juridiques

Mini-site statique pour GitHub Pages. Documents provisoires : remplacer les champs entre crochets et faire valider le contenu avant publication commerciale.

## Publication

1. Sur GitHub, ouvrir le dépôt `motjo-legal`.
2. `Add file` > `Upload files` : déposer les cinq fichiers à la racine du dépôt.
3. `Commit changes`.
4. `Settings` > `Pages` > `Build and deployment` > `Deploy from a branch`.
5. Choisir `main` et `/ (root)`, puis `Save`.
6. Attendre la publication, puis tester les quatre pages et leurs liens.
